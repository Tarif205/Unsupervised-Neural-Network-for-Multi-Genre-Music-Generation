# Unsupervised Neural Network for Multi-Genre Music Generation

Course: CSE425 / EEE474 Neural Networks

This project implements unsupervised generative models for music generation
using MIDI datasets.

Models implemented:
- LSTM Autoencoder
- Variational Autoencoder
- Transformer Music Generator
- RLHF tuning (optional)

Dataset:
- Lakh MIDI Dataset
- MAESTRO Dataset

Structure:
- preprocessing
- model training
- evaluation metrics
- music generation
